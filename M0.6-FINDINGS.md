## 2. The user-context leak — larger than M0.5 reported

### 2.1 Codex `~/.agents/skills` — **no supported mechanism found**

Three mechanisms tested, all against the isolated `CODEX_HOME`:

| Attempt | `.agents\skills` errors | Result |
|---|---|---|
| `CODEX_HOME` only (baseline) | 6 | leak present |
| `CODEX_HOME` + `USERPROFILE`/`HOME`/`HOMEPATH` redirected to a Council user-home | **6** | **no effect** — still resolves `%USERPROFILE%\.agents\skills` |
| `CODEX_HOME` + `-c skills.enabled=false` | **6** | config key **accepted** (no rejection, and the "skills context budget" message changed), but discovery still runs and logs |

`skills.enabled` is a real key — found as a single string in `codex.exe` and not rejected by `--strict-config`-style validation. **Whether it prevents *injection* while still performing discovery is unmeasurable without Codex auth**, because the only decisive test is the ambient token count.

Per your instruction I did not rename, move, or delete `~/.agents/skills`. **Reporting as an architecture constraint.** `VERIFIED` (leak) / `UNVERIFIED` (whether `skills.enabled=false` suppresses injection)

### 2.2 Claude — the leak was worse than M0.5 knew, and it is now solved

M0.5 recorded `CLAUDE_CONFIG_DIR` as "isolates fully". **That was wrong**, and I proved it decisively.

**The decisive test** — every confound removed:
- `CLAUDE_CONFIG_DIR` → isolated dir
- **all file tools disabled** (`--disallowedTools Read Glob Grep Bash Edit Write WebFetch WebSearch Task`)
- **neutral cwd** `C:\m0neutral`, outside the `C:\Users\<USER>` hierarchy
- `--strict-mcp-config`

Result: `num_turns = 1`, and the model reported CLAUDE.md content **"(from system-reminder)"**, citing both `C:\Users\<USER>\CLAUDE.md` and `%USERPROFILE%\.claude\CLAUDE.md`. With tools off and one turn, it could not have read them. **This is context injection, not tool use.** `VERIFIED`

A `USERPROFILE`/`HOME` redirect did not help either (leak persisted, ambient 14,305). `VERIFIED`

**The fix — `--setting-sources local`:**

| Configuration | Ambient | Leak probe result |
|---|---|---|
| `CLAUDE_CONFIG_DIR` only, tools off | 13,441 | **leaks** both CLAUDE.md files |
| `+ USERPROFILE` redirect | 14,305 | **leaks** |
| `+ --setting-sources project` | 13,422 | **leaks** |
| **`+ --setting-sources local`** | **11,405** | **`NONE`** |

`--setting-sources local` suppresses user- and project-level instruction discovery **while preserving OAuth subscription auth**. `VERIFIED`

### 2.3 `--bare` — the trap

`claude --help` documents `--bare` as: *"Minimal mode: skip hooks, LSP, plugin sync, attribution, auto-memory, background prefetches, keychain reads, and CLAUDE.md auto-discovery."*

It would solve isolation perfectly. But the same description continues: *"**Anthropic auth is strictly ANTHROPIC_API_KEY or apiKeyHelper via --settings (OAuth and keychain are never read)**."*

**`--bare` converts the Council into a paid-API consumer.** It directly violates the founding constraint. **Council must never pass `--bare`.** Add it to the forbidden-flags list beside `--dangerously-skip-permissions` and `--yolo`. `VERIFIED`

## 5. Stateless two-turn reconstruction — **the architecture holds**

Turn 2 was a brand-new process. No `--continue`, no `--resume`, no `--conversation`. The packet carried the original question, the agent's verbatim prior position, its prior evidence trail, and one peer claim engineered to be **technically correct** — that the `StateManager` boolean lock is process-local and does not support a database-level single-writer argument.

### Antigravity

It **independently verified the peer's claim** rather than accepting it, and surfaced a *new* citation — `src/core/manager.ts:5` → `private writing = false;` — the exact line that proves the peer right. ### Two schema defects this test exposed — both fixable, both important

**(a) `changed` is ambiguous.** Same concession, opposite values: Antigravity `False` (recommendation unchanged), Claude `True` (reasoning changed). The field must be split:
```
recommendation_changed : boolean
reasoning_changed      : boolean
```
Without this, the belief-revision metric aggregates two different things. `VERIFIED`

**(b) Claude emitted prose citations, not `path:lines`.** Example: `"README.md:4 states single-writer lock exists but doesn't clarify it is application-level only"`. Parseable here only because I extracted paths manually; one Claude "citation" was pure prose with no path at all and is **not machine-verifiable**. The schema must constrain evidence to a strict pattern (`^[^:]+:\d+-\d+$`) in a dedicated field, with commentary in a separate field. `VERIFIED`

| Size | Antigravity | Claude |

| 50 KB | **PASS** 8.2 s, 44,404 tok | **PASS** 5.2 s, 45,126 ctx |

Each packet carried `MARKER_END` at the very end of the file; the task was to return it. **6/6 returned the correct marker**, proving the agents reached the end rather than merely accepting the file. `VERIFIED`

**Codex: untested** (no auth). `UNVERIFIED`

**Important nuance:** token counts do **not** scale with file size (Antigravity: 44 K → 47 K → 51 K for 50 → 500 KB). Both providers **navigate** the packet with search/chunked reads rather than ingesting it wholesale — Claude's `num_turns=3` confirms it. File delivery therefore works, but **Council cannot assume the whole packet is in context**. Packets must be structured so critical content is findable: question and constraints at the top, evidence indexed, no burying decision-relevant material mid-file. `VERIFIED`

## 11. Architecture changes required

**AC-21 — Council Claude invocations must always pass `--setting-sources local`.** It is the only mechanism that isolates user instructions while preserving subscription auth. *Evidence: §2.2.*

**AC-22 — `--bare` is permanently forbidden**, alongside `--dangerously-skip-permissions` and `--yolo`. Add a preflight assertion that rejects it. *Evidence: §2.3.*

**AC-23 — Accept `~/.agents/skills` as an uncontrolled Codex input for V1**, and record its contents hash per debate so contamination is at least *documented* rather than invisible. Re-test `-c skills.enabled=false` by ambient token count once Codex is authenticated. *Evidence: §2.1.*

**AC-24 — Split `changed` into `recommendation_changed` and `reasoning_changed`.** *Evidence: §5(a).*

**AC-25 — Constrain evidence to a strict `path:start-end` pattern** in a dedicated schema field, with prose commentary in a separate field. *Evidence: §5(b).*

**AC-26 — Structure packets for navigation, not ingestion.** Question, constraints, and required schema at the top; evidence indexed; nothing decision-relevant buried. *Evidence: §6.*

**AC-27 — Use `codex login status` as the Codex preflight primitive** (zero cost, exit-code checkable). Equivalent for Claude: a tiny probe returning `is_error` plus the session-limit string. *Evidence: §1.1, §9.*

**AC-28 — Treat session limits as PAUSE with a reset time**, never retry, never paid fallback. *Evidence: §9.*

**AC-29 — Per-seat repair policy is now differentiated:** Claude none, Antigravity one repair, Codex TBD. The repair turn is not a global setting. *Evidence: §4.*
