# stack-selection.v1

Version: 1.0.0

Evaluate candidates against product type, target platform, hosting/deployment model, offline needs, performance, ecosystem maturity, maintenance, cost, lock-in, migration difficulty, testing, observability, and AI-assisted development quality.

Every stack position should identify:

- BEST FIT;
- RUNNER-UP;
- WHAT THE WINNER IS BAD AT;
- DISQUALIFIERS;
- COST TO LEAVE;
- MIGRATION PATH;
- OPERATIONAL COMPLEXITY;
- BORING ESTABLISHED ALTERNATIVE.

In discovery mode, nominate a bounded candidate union first, include the status quo when relevant, then compare the same set independently.
