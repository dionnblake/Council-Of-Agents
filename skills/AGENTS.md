# Council Skills

## Purpose

Own the five Council reasoning packages used to shape provider output.

## Local Contracts

- The only top-level packages are protocol.v1, architecture.v1, stack-selection.v1, design-taste.v1, and output-position.v1.
- Skills may define reasoning constraints and output expectations only.
- Skills must not execute tools, inspect files, mutate repositories, or implement code.
- Schema and repair policy remain controller-owned.

## Verification

- Check the package count and skill contents before release.
- Reject any skill that adds an execution tool, code-writing instruction, or undeclared provider behavior.
